Privacy Policy — Keven rclone

Last updated: 18 September 2026

Who we are

Keven rclone is an application of the Keven project (kevenprojectai). It is used only with the project's own Google account and is not a service offered to other people.

Google user data we access

The application requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. Under this scope the application can access only the files and folders that it creates itself in the connected Google Drive account. It does not access any other Drive files, and it does not access Gmail, Contacts, Calendar, Photos or any other Google service.

How we use the data

The application uses this access solely to upload, verify, list and delete encrypted backup archives that it created, so that the project has an offsite recovery copy of its own files. Archives are encrypted on the computer that creates them, before upload; Google Drive only ever holds encrypted files, and the decryption key is never stored on the computer that runs the backup or in Google Drive.

Storage, sharing and retention

  • Backup archives are stored only in the connected Google Drive account and are deleted automatically when they are older than the project's retention schedule.
  • OAuth credentials are kept in a private configuration file readable only by the project's automation account on its own computer.
  • We do not sell, rent, transfer or disclose Google user data to any third party, we do not use it for advertising, and no human reads Drive content other than the project's own operator, as needed to operate and recover the backups.

Google API Services User Data Policy

Keven rclone's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Backup archives can be deleted directly in Google Drive at any time.

Changes and contact

We will update this page if the application's use of Google data changes. Questions: kevenprojectai@gmail.com.
